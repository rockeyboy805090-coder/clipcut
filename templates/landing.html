How it works

Three steps — link se clip tak.

1

Paste a link or add a streamer

Link dalo ya channel ek baar add karo. Caption style aur clip length choose karo — ya file upload karo, link ki zaroorat nahi.

2

The AI finds the moments

Poori recording transcribe hoti hai, do judges strongest moments pick aur score karte hain, aur vertical captioned clip banta hai. 15-minute video, lagbhag 2 minute me.

3

Download, post, or keep editing

Har clip captioned, scored, aur hook / title / description / hashtags ke saath. Trim karo, style badlo, download karo, ya post queue karo.

Live variant: channel ek baar add karo — live hote hi auto-record shuru, har minute check, aur stream chalte hue captioned clips ready.

Features

Jo ClipCut karta hai — aur jo nahi karta, woh bhi neeche saaf likha hai.

Dual-judge scoring

Words judge sirf transcript padhta hai, reaction judge loudness (aur chat, jab mile) dekhta hai. Clip tabhi banta hai jab dono agree karein — words ≥ 50 aur reaction ≥ 40. Combined score = 0.6 × words + 0.4 × reaction.

Live recorder

Browser se camera/screen record karo — har 60-second chunk se clips live bante hain, stream khatam hone ka wait nahi. Ya channel ka live status check karo aur URL capture karo.

Bring your own key (BYOK)

Gemini, OpenAI, Grok, Groq, OpenRouter, Claude, Ollama ya Custom — apni key, apna provider. Keys Fernet-encrypted save hoti hain, aur har AI call token ledger me dikhti hai (/app/usage).

Posting queue

Rendered clip ko YouTube Shorts, Instagram ya TikTok ke liye schedule karo — pause, resume, cancel, retry. Post tabhi “posted” kehlata hai jab platform real video id de.

Clip editor

Trim start/end, hook aur title rewrite, caption style aur layout switch, phir Re-make — purana version overwrite nahi hota, naya version banta hai. Face-tracking crop bhi hai.

Hindi / Hinglish captions

Caption language English, Hindi (Devanagari) ya Hinglish (Roman). Hindi ke liye Whisper small model chahiye — base model Hindi ko Urdu script me likhta hai, isliye auto-upgrade hota hai.

File upload — no link needed

Reference app me file upload hai hi nahi; yahan hai. Apni video upload karo, wahi pipeline chalega. 100 MB quota per user — full hone par sabse purani video auto-delete.

Test-clip approval gate

Render All tabhi khulta hai jab pehle 1 test clip approve ho. Pehle quality check karo, phir baaki clips render karo.

Honest limits — please read before you sign up

  • YouTube download often fails from a datacenter IP (HTTP 403). YouTube bot-checks server IPs; yt-dlp + impersonation + Invidious fallback wired hain, par guarantee nahi. File upload hamesha kaam karta hai — phone se download karke upload karo.
  • Instagram / TikTok posting is “Not set up on this server”. Inke liye official API + approval chahiye. Queue unhe honestly record karta hai, post karne ka naatak nahi karta. YouTube Shorts posting ke liye aapka Google OAuth client chahiye.
  • Hindi captions need the Whisper small model — slower (~1.4–3.7× realtime) aur ~2× RAM. Render Free (512 MB) par small model ka OOM risk abhi live-tested nahi hai.
  • Gemini words judge kabhi live verify nahi hua — koi key kabhi set nahi hui; bina key ke saare runs rule-based scoring se chalte hain.
  • Render Free: 512 MB RAM, 15 min idle ke baad sleep, ~1 min cold start. Uploads aur database ephemeral hain — restart par wipe ho jate hain. Clips download karke rakhna. YouTube OAuth callback bhi abhi live-untested hai.
  • Brand “ClipCut” placeholder hai — final naam abhi user ka pick baaki hai.

FAQ

Is it really free?

Haan — koi plan ya fees nahi. Sirf kharcha aapki apni AI key ka hai (aur woh bhi optional hai — bina key ke rule-based scoring se clips bante hain).

Which languages do captions support?

English, Hindi (Devanagari) aur Hinglish (Roman). Hindi ke liye Whisper small model chahiye — dekho Honest limits upar.

How long are the clips?

Default 15–60 seconds, 2 clips. Options me count 1–8, shortest 5s, longest 120s tak set kar sakte ho.

Can I post straight to Instagram or TikTok?

Abhi nahi — dono “Not set up on this server” hain. YouTube Shorts queue + OAuth wired hai (aapka OAuth client chahiye). Baaki ke liye clip download karke phone se post karo — share guide app me hai.

My YouTube link fails with 403. Why?

YouTube datacenter IPs ko block karta hai. Yeh ClipCut ki kharabi nahi — reference app aur doosre tools ko bhi wahi error milta hai. File upload use karo.

What happens to my videos on the free server?

Render Free ka filesystem ephemeral hai — restart/sleep par uploads aur database wipe ho sakte hain. 100 MB quota hai; apne clips download karke rakhna.

Do you store my AI key safely?

Aapki key server secret se Fernet-encrypted save hoti hai aur UI me sirf “Saved, ends in …” dikhti hai. Key kabhi full nahi dikhayi jati, aur kabhi pre-filled nahi aati.
